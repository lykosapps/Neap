# Headset support

What each headset Neap knows has of the functions Neap offers. This file is
generated from the headset models in code and kept in step by a test, so change
the models, not this file.

- **Yes** — Neap reads it and offers it.
- **Offered** — the headset has it, but Neap cannot yet read it, so it is shown to be tried.
- **—** — not offered on this headset: either it does not have it, or what it does is
  not yet known. Each headset's file in `docs/headsets` says which.
